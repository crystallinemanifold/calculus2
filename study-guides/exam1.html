What the exam covers

Techniques of integration: \(u\)-substitution, integration by parts, trigonometric integrals, trigonometric substitution, partial fraction decomposition, and improper integrals.

In addition to these topics, be prepared to call upon your own mental faculties to respond in flexible, thoughtful, and creative ways to problems that may seem unfamiliar at first glance.

Work each problem on paper before opening its solution. Most solutions give the final answer; the mixed-method problems also name an approach that works.

Problems 69–79

Improper integrals

Determine whether each integral is convergent or divergent. Evaluate those that are convergent.

69
\(\displaystyle \int_3^{\infty} \frac{1}{(x-2)^{3/2}} \, dx\)
SolutionHide solution

Approach\(\lim_{t\to\infty}\left[-2(x-2)^{-1/2}\right]_3^t = 0 - (-2) = 2\).

Converges to \(2\).

70
\(\displaystyle \int_{-\infty}^{0} \frac{1}{3-4x} \, dx\)
SolutionHide solution

Approach\(\int_t^0 \frac{dx}{3-4x} = -\frac{1}{4}\ln 3 + \frac{1}{4}\ln(3-4t) \to \infty\) as \(t \to -\infty\).

Diverges.

71
\(\displaystyle \int_0^{\infty} \frac{1}{\sqrt{x}(1+x)} \, dx\)
SolutionHide solution

Approach\(u = \sqrt{x}\) gives \(2\int_0^\infty \frac{du}{1+u^2} = 2\cdot\frac{\pi}{2}\). (Improper at both ends.)

Converges to \(\pi\).

72
\(\displaystyle \int_0^{\infty} \frac{e^x}{e^{2x}+3} \, dx\)
SolutionHide solution

Approach\(u = e^x\): \(\int_1^\infty \frac{du}{u^2+3} = \frac{1}{\sqrt{3}}\left(\frac{\pi}{2} - \frac{\pi}{6}\right)\).

Converges to \(\dfrac{\pi}{3\sqrt{3}}\).

73
\(\displaystyle \int_0^{\infty} \sin^2 x \, dx\)
SolutionHide solution

Approach\(\int_0^t \sin^2 x\,dx = \frac{t}{2} - \frac{\sin 2t}{4} \to \infty\).

Diverges.

74
\(\displaystyle \int_{-\infty}^{\infty} x^3 e^{-x^4} \, dx\)
SolutionHide solution

Approach\(\int_0^\infty x^3e^{-x^4}\,dx = \frac{1}{4}\) and \(\int_{-\infty}^0 x^3e^{-x^4}\,dx = -\frac{1}{4}\). Both halves converge, so the total is \(0\).

Converges to \(0\).

75
\(\displaystyle \int_1^{\infty} \frac{e^{-\sqrt{x}}}{\sqrt{x}} \, dx\)
SolutionHide solution

Approach\(u = \sqrt{x}\): \(2\int_1^\infty e^{-u}\,du = 2e^{-1}\).

Converges to \(\dfrac{2}{e}\).

76
\(\displaystyle \int_{-2}^{3} \frac{1}{x^4} \, dx\)
SolutionHide solution

ApproachInfinite discontinuity at \(x = 0\); \(\int_0^3 x^{-4}\,dx = \lim_{t\to 0^+}\left[-\frac{1}{3x^3}\right]_t^3 = \infty\).

Diverges.

77
\(\displaystyle \int_2^{3} \frac{1}{\sqrt{3-x}} \, dx\)
SolutionHide solution

ApproachImproper at \(x = 3\): \(\lim_{t\to 3^-}\left[-2\sqrt{3-x}\right]_2^t = 2\).

Converges to \(2\).

78
\(\displaystyle \int_0^{5} \frac{x}{x-2} \, dx\)
SolutionHide solution

Approach\(\frac{x}{x-2} = 1 + \frac{2}{x-2}\), and \(\int \frac{2}{x-2}\,dx = 2\ln|x-2|\) blows up at \(x = 2\).

Diverges.

79
\(\displaystyle \int_0^{2} x^2\ln x \, dx\)
SolutionHide solution

ApproachIntegration by parts: \(\frac{x^3}{3}\ln x - \frac{x^3}{9}\), and \(\lim_{x\to 0^+} x^3\ln x = 0\).

Converges to \(\dfrac{8}{3}\ln 2 - \dfrac{8}{9}\).

Problems 80–83

Comparison theorem

Use the Comparison Theorem to determine whether the integral is convergent or divergent.

80
\(\displaystyle \int_0^{\infty} \frac{x}{x^3+1} \, dx\)
SolutionHide solution

Approach\(\int_0^1\) is a proper integral; for \(x \ge 1\), \(\frac{x}{x^3+1} \le \frac{x}{x^3} = \frac{1}{x^2}\), and \(\int_1^\infty \frac{dx}{x^2}\) converges.

Convergent.

81
\(\displaystyle \int_1^{\infty} \frac{2 + e^{-x}}{x} \, dx\)
SolutionHide solution

Approach\(\frac{2+e^{-x}}{x} \ge \frac{2}{x}\), and \(\int_1^\infty \frac{2}{x}\,dx\) diverges.

Divergent.

82
\(\displaystyle \int_1^{\infty} \frac{x+1}{\sqrt{x^4 - x}} \, dx\)
SolutionHide solution

Approach\(\frac{x+1}{\sqrt{x^4-x}} \gt \frac{x}{\sqrt{x^4}} = \frac{1}{x}\), and \(\int_1^\infty \frac{dx}{x}\) diverges.

Divergent.

83
\(\displaystyle \int_0^{\infty} \frac{\arctan x}{2 + e^x} \, dx\)
SolutionHide solution

Approach\(\frac{\arctan x}{2+e^x} \le \frac{\pi/2}{e^x}\), and \(\int_0^\infty \frac{\pi}{2}e^{-x}\,dx\) converges.

Convergent.

Problems 84–85

Arc length

84
Use calculus to find the arc length of the curve \(y = \sqrt{2 - x^2}\), \(0 \le x \le \sqrt{2}\).
SolutionHide solution

Approach\(1 + (y')^2 = \frac{2}{2-x^2}\), so \(L = \int_0^{\sqrt2}\frac{\sqrt{2}}{\sqrt{2-x^2}}\,dx\). (Check: a quarter of a circle of radius \(\sqrt{2}\).)

\(\displaystyle \frac{\pi}{\sqrt{2}}\)

85
Find the exact length of the curve using calculus: \(y = \ln(\sec x)\), \(0 \le x \le \frac{\pi}{4}\).
SolutionHide solution

Approach\(y' = \tan x\), so \(\sqrt{1 + \tan^2 x} = \sec x\) and \(L = \int_0^{\pi/4}\sec x\,dx\).

\(\displaystyle \ln\!\left(1 + \sqrt{2}\right) = -\frac{1}{2}\ln\!\left(3 - 2\sqrt{2}\right)\)
