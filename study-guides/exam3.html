What you should know and be able to do

  • Although the exam directly tests sequences and series, it indirectly tests mastery of the previous chapters.
  • Define a sequence explicitly or recursively from the terms of the sequence.
  • Compute the limit of a sequence.
  • State and use the Monotone Sequence Theorem.
  • Explain the difference between a sequence and a series.
  • Explain what it means for a sequence or a series to converge (partial sums).
  • Geometric, telescoping, harmonic, and \(p\)-series.
  • State the following tests in detail and apply them to determine convergence or divergence: Divergence Test, Integral Test, Comparison Test, Limit Comparison Test, Alternating Series Test, Ratio Test, Root Test.
  • Call upon your own mental faculties to respond in flexible, thoughtful, and creative ways to problems that may seem unfamiliar at first glance.
Reference: series convergence tests
TestSeriesConclusion
Divergence Test\(\sum a_n\)If \(\lim_{n\to\infty} a_n \neq 0\) (or does not exist), the series diverges. If the limit is \(0\), the test says nothing.
Geometric series\(\displaystyle\sum_{n=1}^\infty ar^{n-1}\)Converges if \(|r| \lt 1\), with sum \(\dfrac{a}{1-r}\); diverges if \(|r| \ge 1\).
\(p\)-series\(\displaystyle\sum_{n=1}^\infty \frac{1}{n^p}\)Converges if \(p \gt 1\); diverges if \(p \le 1\).
Integral Test\(a_n = f(n)\), \(f\) continuous, positive, decreasing\(\sum a_n\) and \(\int_1^\infty f(x)\,dx\) both converge or both diverge.
Comparison\(0 \le a_n \le b_n\)If \(\sum b_n\) converges, so does \(\sum a_n\). If \(\sum a_n\) diverges, so does \(\sum b_n\).
Limit Comparison\(a_n, b_n \gt 0\), \(\lim\limits_{n\to\infty}\dfrac{a_n}{b_n} = L\)If \(0 \lt L \lt \infty\), both series converge or both diverge.
Alternating Series Test\(\sum (-1)^n b_n\), \(b_n \gt 0\)If \(b_n\) is decreasing and \(\lim b_n = 0\), the series converges.
Absolute convergence\(\sum a_n\)If \(\sum |a_n|\) converges, then \(\sum a_n\) converges (absolutely). Convergent but not absolutely convergent means conditionally convergent.
Ratio Test\(\lim\limits_{n\to\infty}\left|\dfrac{a_{n+1}}{a_n}\right| = L\)\(L \lt 1\): converges absolutely. \(L \gt 1\): diverges. \(L = 1\): inconclusive.
Root Test\(\lim\limits_{n\to\infty}\sqrt[n]{|a_n|} = L\)\(L \lt 1\): converges absolutely. \(L \gt 1\): diverges. \(L = 1\): inconclusive.
Problems 1–5

Definitions and concepts

1
What is a bounded sequence? What is a monotonic sequence? What can you say about a bounded monotonic sequence?
SolutionHide solution

Bounded: there are numbers \(m\) and \(M\) with \(m \le a_n \le M\) for every \(n\).

Monotonic: the sequence is either increasing (\(a_n \le a_{n+1}\) for all \(n\)) or decreasing (\(a_n \ge a_{n+1}\) for all \(n\)).

Monotone Sequence Theorem: every bounded, monotonic sequence converges.

2
What is a convergent sequence? What is a convergent series? Explain what it means to say \(\displaystyle\lim_{n\to\infty} a_n = 3\). What does it mean to say \(\displaystyle\sum_{n=1}^\infty a_n = 3\)?
SolutionHide solution

A sequence \(\{a_n\}\) converges if \(\lim_{n\to\infty} a_n\) exists as a finite number.

A series \(\sum a_n\) converges if its sequence of partial sums \(S_N = a_1 + a_2 + \cdots + a_N\) converges.

\(\lim_{n\to\infty} a_n = 3\) means the terms \(a_n\) can be made as close to 3 as we like by taking \(n\) large enough.

\(\sum_{n=1}^\infty a_n = 3\) means the partial sums approach 3: \(\lim_{N\to\infty} S_N = 3\). (In that case the terms themselves must approach 0.)

3
What is a geometric series? Under what circumstances is it convergent? What is its sum?
SolutionHide solution

A series in which each term is a fixed multiple \(r\) of the previous one: \(\displaystyle\sum_{n=1}^\infty ar^{n-1} = a + ar + ar^2 + \cdots\)

It converges exactly when \(|r| \lt 1\), and then its sum is \(\dfrac{a}{1-r}\) (first term over one minus the ratio). It diverges when \(|r| \ge 1\) (and \(a \ne 0\)).

4
What is a \(p\)-series? Under what circumstances is it convergent?
SolutionHide solution

\(\displaystyle\sum_{n=1}^\infty \frac{1}{n^p}\). It converges if \(p \gt 1\) and diverges if \(p \le 1\). (The harmonic series is the case \(p = 1\).)

5
Suppose \(\sum a_n = 3\) and \(S_n\) is the \(n\)th partial sum of the series. What is \(\lim_{n\to\infty} a_n\)? What is \(\lim_{n\to\infty} S_n\)?
SolutionHide solution

\(\lim_{n\to\infty} a_n = 0\), because \(a_n = S_n - S_{n-1} \to 3 - 3 = 0\).

\(\lim_{n\to\infty} S_n = 3\), by the definition of the sum of a series.

Problem 6

True or false

6
True or false. If the statement is true, provide an explanation. If it is false, provide an example that disproves the statement.
  1. (a)
    If \(\lim_{n\to\infty} a_n = 0\), then \(\sum a_n\) is convergent.
    SolutionHide solution

    False.

    The harmonic series: \(\frac{1}{n} \to 0\), but \(\sum \frac{1}{n}\) diverges.

  2. (b)
    If \(\lim_{n\to\infty} a_n = L\), then \(\lim_{n\to\infty} a_{2n+1} = L\).
    SolutionHide solution

    True.

    \(\{a_{2n+1}\}\) is a subsequence of \(\{a_n\}\): once \(a_n\) is within \(\varepsilon\) of \(L\) for all large \(n\), so is every \(a_{2n+1}\).

  3. (c)
    The ratio test can be used to determine whether \(\sum 1/n^3\) converges.
    SolutionHide solution

    False.

    \(\dfrac{a_{n+1}}{a_n} = \dfrac{n^3}{(n+1)^3} \to 1\), so the ratio test is inconclusive. (The series converges, as a \(p\)-series with \(p = 3\).)

  4. (d)
    The ratio test can be used to determine whether \(\sum 1/n!\) converges.
    SolutionHide solution

    True.

    \(\dfrac{a_{n+1}}{a_n} = \dfrac{1}{n+1} \to 0 \lt 1\), so the series converges.

  5. (e)
    If \(0 \le a_n \le b_n\) and \(\sum b_n\) diverges, then \(\sum a_n\) diverges.
    SolutionHide solution

    False.

    \(a_n = \frac{1}{n^2}\), \(b_n = \frac{1}{n}\). A smaller series can converge underneath a divergent one.

  6. (f)
    If \(\sum a_n\) diverges, then \(\sum |a_n|\) diverges.
    SolutionHide solution

    True.

    If \(\sum |a_n|\) converged, then \(\sum a_n\) would converge (absolute convergence implies convergence). This is the contrapositive.

  7. (g)
    If \(\{a_n\}\) and \(\{b_n\}\) are divergent, then \(\{a_n + b_n\}\) is divergent.
    SolutionHide solution

    False.

    \(a_n = n\), \(b_n = -n\): both diverge, but \(a_n + b_n = 0\) converges.

  8. (h)
    If \(\{a_n\}\) and \(\{b_n\}\) are divergent, then \(\{a_n b_n\}\) is divergent.
    SolutionHide solution

    False.

    \(a_n = b_n = (-1)^n\): both diverge, but \(a_n b_n = 1\) converges.

  9. (i)
    If \(\{a_n\}\) is decreasing and \(a_n \gt 0\) for all \(n\), then \(\{a_n\}\) is convergent.
    SolutionHide solution

    True.

    The sequence is monotonic and bounded (between \(0\) and \(a_1\)), so it converges by the Monotone Sequence Theorem.

  10. (j)
    If \(a_n \gt 0\) and \(\sum a_n\) converges, then \(\sum (-1)^n a_n\) converges.
    SolutionHide solution

    True.

    \(\sum |(-1)^n a_n| = \sum a_n\) converges, so \(\sum (-1)^n a_n\) converges absolutely.

  11. (k)
    If \(a_n \gt 0\) and \(\lim_{n\to\infty}(a_{n+1}/a_n) \lt 1\), then \(\lim_{n\to\infty} a_n = 0\).
    SolutionHide solution

    True.

    By the ratio test, \(\sum a_n\) converges, and the terms of a convergent series tend to 0.

  12. (l)
    If \(\lim_{n\to\infty} a_n = 2\), then \(\lim_{n\to\infty}(a_{n+3} - a_n) = 0\).
    SolutionHide solution

    True.

    \(a_{n+3} \to 2\) and \(a_n \to 2\), so the difference tends to \(2 - 2 = 0\).

  13. (m)
    If a finite number of terms are added to a convergent series, then the new series is still convergent.
    SolutionHide solution

    True.

    Adding finitely many terms changes every partial sum (from some point on) by the same fixed number, so the partial sums still have a limit.

  14. (n)
    If \(\sum_{n=1}^\infty a_n = A\) and \(\sum_{n=1}^\infty b_n = B\), then \(\sum_{n=1}^\infty a_n b_n = AB\).
    SolutionHide solution

    False.

    \(a_n = b_n = \left(\tfrac{1}{2}\right)^n\): \(A = B = 1\), but \(\sum \left(\tfrac{1}{4}\right)^n = \tfrac{1}{3} \ne 1\).

Problem 7

Examples and non-examples

7
Give an example of the following or explain why such an example is impossible.
  1. (a)
    A sequence \(\{a_n\}\) that converges but \(\sum a_n\) diverges.
    SolutionHide solution

    \(a_n = \frac{1}{n}\): the sequence converges to 0, but the harmonic series diverges.

  2. (b)
    A sequence \(\{a_n\}\) that diverges but \(\sum a_n\) converges.
    SolutionHide solution

    Impossible. If \(\sum a_n\) converges, then \(a_n \to 0\), so the sequence converges.

  3. (c)
    An increasing sequence that converges to \(-3\).
    SolutionHide solution

    \(a_n = -3 - \frac{1}{n}\).

  4. (d)
    A sequence that is bounded between \(3\) and \(7\) but does not converge.
    SolutionHide solution

    \(a_n = 5 + (-1)^n\), which alternates \(4, 6, 4, 6, \ldots\)

  5. (e)
    A decreasing sequence that is bounded below by \(1\) but does not converge.
    SolutionHide solution

    Impossible. A decreasing sequence that is bounded below is monotonic and bounded, so it converges by the Monotone Sequence Theorem.

  6. (f)
    An infinite series that converges to \(431\).
    SolutionHide solution

    \(\displaystyle\sum_{n=1}^\infty 431\left(\tfrac{1}{2}\right)^n = 431\cdot\frac{1/2}{1 - 1/2} = 431\).

  7. (g)
    A pair of series \(\sum a_n\) and \(\sum b_n\) with positive terms where \(\lim_{n\to\infty}\frac{a_n}{b_n} = 0\) and \(\sum b_n\) diverges, but \(\sum a_n\) converges.
    SolutionHide solution

    \(a_n = \frac{1}{n^2}\), \(b_n = \frac{1}{n}\): \(\frac{a_n}{b_n} = \frac{1}{n} \to 0\).

  8. (h)
    A sequence of non-negative terms \(\{a_n\}\) where \(\lim_{n\to\infty} a_n = 0\) and \(\sum_{n=1}^\infty (-1)^n a_n\) diverges.
    SolutionHide solution

    \(a_n = \frac{1}{n}\) for even \(n\) and \(a_n = 0\) for odd \(n\). Then \(\sum (-1)^n a_n = \frac{1}{2} + \frac{1}{4} + \frac{1}{6} + \cdots = \frac{1}{2}\sum \frac{1}{k}\), which diverges. (The Alternating Series Test does not apply because \(a_n\) is not decreasing.)

  9. (i)
    A series for which the ratio test is inconclusive.
    SolutionHide solution

    \(\sum \frac{1}{n}\) (or any \(p\)-series): the ratio \(\frac{n}{n+1} \to 1\).

Problems 8–9

Thinking about series

8
Let \(x = 0.99999999999\ldots\)
  1. (a)
    Do you think that \(x \lt 1\) or \(x = 1\)?
    SolutionHide solution

    \(x = 1\). (There is no number strictly between \(0.999\ldots\) and \(1\).)

  2. (b)
    Sum a geometric series to find the value of \(x\).
    SolutionHide solution

    \(\displaystyle x = \frac{9}{10} + \frac{9}{100} + \frac{9}{1000} + \cdots = \frac{9/10}{1 - 1/10} = 1\)

9
What is wrong with the following calculation? \[ \begin{aligned} 0 &= 0 + 0 + 0 + \cdots \\ &= (1 - 1) + (1 - 1) + (1 - 1) + \cdots \\ &= 1 - 1 + 1 - 1 + 1 - 1 + \cdots \\ &= 1 + (-1 + 1) + (-1 + 1) + (-1 + 1) + \cdots \\ &= 1 + 0 + 0 + 0 + \cdots = 1 \end{aligned} \]

(Guido Ubaldus thought that this proved the existence of God because “something has been created from nothing.”)

SolutionHide solution

Removing the parentheses (line 2 to line 3) produces the series \(\sum (-1)^{n+1} = 1 - 1 + 1 - \cdots\), which diverges: its partial sums alternate \(1, 0, 1, 0, \ldots\) and have no limit (and its terms do not approach 0).

Grouping or ungrouping terms is only safe for a convergent series. Lines 2 and 4 are two different groupings of the same divergent series, so they need not agree.

Problems 10–12

Short proofs

10
Prove that if \(a_n \ge 0\) and \(\sum a_n\) converges, then \(\sum a_n^2\) also converges.
SolutionHide solution

Since \(\sum a_n\) converges, \(a_n \to 0\). So there is an \(N\) with \(0 \le a_n \lt 1\) for all \(n \ge N\).

For those \(n\), \(a_n^2 = a_n\cdot a_n \le a_n\). Since \(\sum a_n\) converges, \(\sum a_n^2\) converges by the Comparison Test (the first \(N\) terms do not affect convergence).

11
Suppose that \(\sum a_n\) and \(\sum b_n\) are series with positive terms and \(\sum b_n\) is convergent. Prove that if \[\lim_{n\to\infty}\frac{a_n}{b_n} = 0\] then \(\sum a_n\) is also convergent.
SolutionHide solution

Because the limit is \(0\), there is an \(N\) such that \(\frac{a_n}{b_n} \lt 1\) for all \(n \ge N\); that is, \(0 \lt a_n \lt b_n\).

Since \(\sum b_n\) converges, \(\sum_{n \ge N} a_n\) converges by the Comparison Test, and so does \(\sum a_n\).

12
Suppose that \(\sum a_n\) and \(\sum b_n\) are series with positive terms and \(\sum b_n\) is divergent. Prove that if \[\lim_{n\to\infty}\frac{a_n}{b_n} = \infty\] then \(\sum a_n\) is also divergent.
SolutionHide solution

Because the limit is \(\infty\), there is an \(N\) such that \(\frac{a_n}{b_n} \gt 1\) for all \(n \ge N\); that is, \(a_n \gt b_n \gt 0\).

Since \(\sum b_n\) diverges, \(\sum_{n\ge N} a_n\) diverges by the Comparison Test, and so does \(\sum a_n\).

Problem 13

Limits of sequences

13
Determine whether the following sequences \(\{a_n\}\) converge or diverge. Find the limit of the convergent sequences. Justify your answers (e.g. geometric sequence, L’Hôpital’s Rule, Squeeze Theorem, Monotone Sequence Theorem).
  1. (a)
    \(\displaystyle a_n = \frac{e^n}{3^n}\)
    SolutionHide solution

    Converges to \(0\).

    Geometric sequence \(\left(\frac{e}{3}\right)^n\) with \(\left|\frac{e}{3}\right| \lt 1\).

  2. (b)
    \(\displaystyle a_n = \frac{3^n}{e^n}\)
    SolutionHide solution

    Diverges.

    Geometric sequence \(\left(\frac{3}{e}\right)^n\) with \(\frac{3}{e} \gt 1\).

  3. (c)
    \(\displaystyle a_n = \frac{\sin^3 n}{n^2 + n}\)
    SolutionHide solution

    Converges to \(0\).

    Squeeze Theorem: \(\dfrac{-1}{n^2+n} \le \dfrac{\sin^3 n}{n^2+n} \le \dfrac{1}{n^2+n}\).

  4. (d)
    \(\displaystyle a_n = \frac{n^3 - 4}{3n^3 - 2n^2 + 1}\)
    SolutionHide solution

    Converges to \(\frac{1}{3}\).

    Divide the numerator and denominator by \(n^3\).

  5. (e)
    \(\displaystyle a_n = \frac{\sqrt{n}}{n + 3}\)
    SolutionHide solution

    Converges to \(0\).

    Divide the numerator and denominator by \(n\) (or use L’Hôpital’s Rule).

  6. (f)
    \(\displaystyle a_n = ne^{-n}\)
    SolutionHide solution

    Converges to \(0\).

    L’Hôpital’s Rule on \(\frac{x}{e^x}\): \(\lim \frac{1}{e^x} = 0\).

Problem 14

Sums of series

14
Find the sum of the series (if it exists at all).
  1. (a)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{5^n}{6^{n-1}}\)
    SolutionHide solution

    \(30\)

    Geometric: first term \(a = 5\), ratio \(r = \frac{5}{6}\); sum \(= \frac{5}{1 - 5/6} = 30\).

  2. (b)
    \(\displaystyle \sum_{n=2}^{\infty}\left(\frac{4}{9}\right)^n\)
    SolutionHide solution

    \(\frac{16}{45}\)

    Geometric: first term \(a = \frac{16}{81}\), ratio \(r = \frac{4}{9}\); sum \(= \frac{16/81}{5/9} = \frac{16}{45}\).

  3. (c)
    \(\displaystyle \sum_{n=1}^{\infty}\left(\frac{3}{n} - \frac{3}{n+2}\right)\)
    SolutionHide solution

    \(\frac{9}{2}\)

    Telescoping: \(S_N = 3\left(1 + \frac{1}{2} - \frac{1}{N+1} - \frac{1}{N+2}\right) \to \frac{9}{2}\).

  4. (d)
    \(\displaystyle \sum_{n=2}^{\infty}\frac{2}{n(n-1)}\) (Hint: \(\frac{1}{n(n-1)} = \frac{1}{n-1} - \frac{1}{n}\))
    SolutionHide solution

    \(2\)

    Telescoping: \(\frac{2}{n(n-1)} = 2\left(\frac{1}{n-1} - \frac{1}{n}\right)\), so \(S_N = 2\left(1 - \frac{1}{N}\right) \to 2\).

Problem 15

Choosing a convergence test

15
Determine whether the following series converge or diverge. Specify which tests you would use to make your conclusions. Show all work necessary for the tests you choose, and make sure you check the conditions for using the test.
  1. (a)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{n-1}{2n-1}\)
    SolutionHide solution

    Diverges (Divergence Test).

    \(\lim \frac{n-1}{2n-1} = \frac{1}{2} \ne 0\).

  2. (b)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{\sqrt{n^3+1}}{3n^3+4n^2+2}\)
    SolutionHide solution

    Converges (Limit Comparison Test).

    Compare with \(b_n = \frac{1}{n^{3/2}}\): \(\frac{a_n}{b_n} \to \frac{1}{3}\), and \(\sum \frac{1}{n^{3/2}}\) converges (\(p = \frac{3}{2} \gt 1\)).

  3. (c)
    \(\displaystyle \sum_{n=1}^{\infty} n e^{-n^2}\) (use the integral test and a \(u\)-substitution)
    SolutionHide solution

    Converges (Integral Test).

    \(f(x) = xe^{-x^2}\) is positive, continuous, and decreasing for \(x \ge 1\); with \(u = x^2\), \(\int_1^\infty xe^{-x^2}\,dx = \frac{1}{2e}\).

  4. (d)
    \(\displaystyle \sum_{n=1}^{\infty}(-1)^n\frac{n^3}{n^4+1}\)
    SolutionHide solution

    Converges (Alternating Series Test).

    \(b_n = \frac{n^3}{n^4+1}\) is positive, eventually decreasing, and \(b_n \to 0\).

  5. (e)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{2^n}{n!}\)
    SolutionHide solution

    Converges (Ratio Test).

    \(\frac{a_{n+1}}{a_n} = \frac{2}{n+1} \to 0 \lt 1\).

  6. (f)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{1}{2+3^n}\)
    SolutionHide solution

    Converges (Comparison Test).

    \(\frac{1}{2+3^n} \lt \frac{1}{3^n}\), a convergent geometric series.

  7. (g)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{(-3)^{n+1}}{2^{3n}}\)
    SolutionHide solution

    Converges (geometric).

    \(\frac{(-3)^{n+1}}{8^n} = -3\left(-\frac{3}{8}\right)^n\), geometric with \(|r| = \frac{3}{8} \lt 1\). (Its sum is \(\frac{9}{11}\).)

  8. (h)
    \(\displaystyle \sum_{n=2}^{\infty}\frac{1}{n\sqrt{\ln n}}\)
    SolutionHide solution

    Diverges (Integral Test).

    With \(u = \ln x\), \(\int_2^\infty \frac{dx}{x\sqrt{\ln x}} = \int_{\ln 2}^\infty u^{-1/2}\,du = \infty\).

  9. (i)
    \(\displaystyle \sum_{n=2}^{\infty}\frac{(-1)^n}{n\ln n}\)
    SolutionHide solution

    Converges (Alternating Series Test).

    \(b_n = \frac{1}{n\ln n}\) is positive, decreasing, and \(b_n \to 0\).

  10. (j)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{n^2+1}{n^3+1}\)
    SolutionHide solution

    Diverges (Limit Comparison Test).

    Compare with \(\frac{1}{n}\): the ratio \(\to 1\), and the harmonic series diverges.

  11. (k)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{n^2+1}{n^4+1}\)
    SolutionHide solution

    Converges (Limit Comparison Test).

    Compare with \(\frac{1}{n^2}\): the ratio \(\to 1\), and \(\sum \frac{1}{n^2}\) converges.

  12. (l)
    \(\displaystyle \sum_{n=1}^{\infty}(-1)^n\frac{n^2+1}{n^3+1}\)
    SolutionHide solution

    Converges (Alternating Series Test).

    \(b_n = \frac{n^2+1}{n^3+1}\) is positive, eventually decreasing, and \(b_n \to 0\).

  13. (m)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{n}{n + n\cos^2 n}\)
    SolutionHide solution

    Diverges (Divergence Test).

    \(\frac{n}{n + n\cos^2 n} = \frac{1}{1 + \cos^2 n} \ge \frac{1}{2}\), so the terms do not approach 0.

  14. (n)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{\arctan n}{n\sqrt{n}}\)
    SolutionHide solution

    Converges (Limit Comparison Test).

    Compare with \(\frac{1}{n^{3/2}}\): the ratio \(= \arctan n \to \frac{\pi}{2}\). (Direct comparison also works: \(\arctan n \lt \frac{\pi}{2}\).)

  15. (o)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{5^n}{3^n+4^n}\)
    SolutionHide solution

    Diverges (Comparison Test).

    \(\frac{5^n}{3^n+4^n} \ge \frac{5^n}{2\cdot 4^n} = \frac{1}{2}\left(\frac{5}{4}\right)^n\), a divergent geometric series. (The terms even grow without bound.)

  16. (p)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{n+5}{5^n}\)
    SolutionHide solution

    Converges (Ratio Test).

    \(\frac{a_{n+1}}{a_n} = \frac{n+6}{5(n+5)} \to \frac{1}{5} \lt 1\).

Problem 16

Absolute and conditional convergence

16
Determine whether the following series diverge, converge conditionally, or converge absolutely.
  1. (a)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{\cos n}{n^5}\)
    SolutionHide solution

    Converges absolutely.

    \(\left|\frac{\cos n}{n^5}\right| \le \frac{1}{n^5}\), a convergent \(p\)-series.

  2. (b)
    \(\displaystyle \sum_{n=3}^{\infty}(-1)^n\frac{5}{n-2}\)
    SolutionHide solution

    Converges conditionally.

    Converges by the Alternating Series Test, but \(\sum \frac{5}{n-2}\) diverges (limit comparison with \(\frac{1}{n}\)).

  3. (c)
    \(\displaystyle \sum_{n=2}^{\infty}(-1)^n\frac{1}{n\ln n}\)
    SolutionHide solution

    Converges conditionally.

    Converges by the Alternating Series Test, but \(\sum \frac{1}{n\ln n}\) diverges by the Integral Test.

  4. (d)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{n!}{100^n}\)
    SolutionHide solution

    Diverges.

    Ratio Test: \(\frac{a_{n+1}}{a_n} = \frac{n+1}{100} \to \infty\). (So the terms do not approach 0.)

  5. (e)
    \(\displaystyle \sum_{n=1}^{\infty}(-1)^n\frac{e^{1/n}}{n^3}\)
    SolutionHide solution

    Converges absolutely.

    \(\frac{e^{1/n}}{n^3}\): limit comparison with \(\frac{1}{n^3}\) (ratio \(e^{1/n} \to 1\)).

  6. (f)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{10^n}{(n+1)4^{2n+1}}\)
    SolutionHide solution

    Converges absolutely.

    Ratio Test: \(\frac{a_{n+1}}{a_n} = \frac{10(n+1)}{16(n+2)} \to \frac{5}{8} \lt 1\).

  7. (g)
    \(\displaystyle \sum_{n=1}^{\infty}\left(\frac{-2n}{n+1}\right)^{5n}\)
    SolutionHide solution

    Diverges.

    Root Test: \(\sqrt[n]{|a_n|} = \left(\frac{2n}{n+1}\right)^5 \to 32 \gt 1\).

  8. (h)
    \(\displaystyle \sum_{n=1}^{\infty}\left(1 + \frac{1}{n}\right)^{n^2}\)
    SolutionHide solution

    Diverges.

    Root Test: \(\sqrt[n]{a_n} = \left(1 + \frac{1}{n}\right)^n \to e \gt 1\).

  9. (i)
    \(\displaystyle \sum_{n=1}^{\infty}\frac{2^{n^2}}{n!}\)
    SolutionHide solution

    Diverges.

    Ratio Test: \(\frac{a_{n+1}}{a_n} = \frac{2^{(n+1)^2 - n^2}}{n+1} = \frac{2^{2n+1}}{n+1} \to \infty\).

Problem 17

A challenge

17
For which positive integers \(k\) is the following series convergent? \(\displaystyle\sum_{n=1}^\infty \frac{(n!)^2}{(kn)!}\)
SolutionHide solution

\(k \ge 2\).

Ratio Test: \(\dfrac{a_{n+1}}{a_n} = \dfrac{(n+1)^2}{(kn+1)(kn+2)\cdots(kn+k)}\).

For \(k = 1\) this is \(n + 1 \to \infty\) (diverges). For \(k = 2\) it tends to \(\frac{1}{4} \lt 1\). For \(k \ge 3\) the denominator has degree \(k \gt 2\), so it tends to \(0\).
